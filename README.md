# Sara · Weekly Race Report

NYSSRA slalom and giant slalom results for Sara (Windham Mountain Club), 2024-25 and 2025-26 seasons, with a weekly update during the 2026-27 season.

Live page: https://philippe145.github.io/sara-krolicki-weekly-race-report/

- **Season**: place, % behind the winner, run 1 and run 2 ranks, class and club place, distance to the top 10 and the podium.
- **Race by race** and **Rivals** (racers met in at least three races).
- **Hill types**: performance by course type, classified by vertical drop (bands scaled to youth courses).
- **Venue ranking**: next season's races ranked from best to worst predicted result, and how earlier predictions compared with actual results.
- **U18 outlook**: her times placed among U18 finishers of the same races.

Racers are shown by first name only; an anonymous code links each racer's results across races. Data: live-timing.com, vola.ussalivetiming.com and AdminSkiRacing official tables. All figures are computed in the page from `data/races.json`.
